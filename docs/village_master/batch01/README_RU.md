## rm_village
- `village_grass_32` (depth 648): вся комната; база grass_00, ~30% редких вариантов.
- `village_sand_32` (depth 645): чистые клетки песка — mask_15 и варианты 16–19.
- `ground_concept` (depth 640): остались только клетки с камнем (площадь и бордюры вдоль дорог), слой переключён на olive-копию с теми же индексами.
- Геометрия дорог, развилки, ширина, объекты, переходы — без изменений. Старые скрытые слои не тронуты.

## Почему края песка из партии пока не видны
В текущей земле бордюры вдоль дорог «вшиты» в песчаные клетки. Мягкие края песка из партии (маски 1–14) можно показать только убрав эти бордюры — а бордюры в этой партии менять нельзя. Вариант без бордюров вдоль дорог: `99_alt_soft_edges_without_road_curbs.png` (скрипт `tools/village/b01_ground.py` собирает такие тайлы по клеткам комнаты из четвертинок присланных — без перерисовки).
