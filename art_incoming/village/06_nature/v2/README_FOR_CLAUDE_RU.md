# Pixel Game — Nature Redraw Sprite Pack V2

Это пакет спрайтов природы, вырезанный из утверждённого листа MASTER_REFERENCE_NATURE.png.

## Состав
- trees/ — деревья
- bushes/ — кусты
- grass/ — травинки и небольшие пучки
- flowers/ — цветочные акценты и маленькие клумбы
- SPRITES_MANIFEST.csv — список файлов и размеров
- MASTER_REFERENCE_NATURE.png — референс, из которого всё вырезано
- PREVIEW_ALL_SPRITES.png — обзор всех PNG
- TASK_FOR_CLAUDE_RU.txt — готовый текст задания для Claude

## Принцип
Нужно использовать эти спрайты как основу и расставить природу в деревне без новой стилизации, максимально близко к approved master scene.
