# Pixel-Game — RIVER V3 / CLEAN BRIDGE (замена прежней версии)

## Что изменилось

- **Мост полностью заменён** новой, одобренной версией с ровными краями, без рваных углов и фрагментов травы/воды.
- Для прозрачности используется бинарная альфа (0 или 255), чтобы избежать ореолов на фоне реки.
- `deck` и `front_rail` выделены из **ОДНОГО** полного мостика; их точное наложение даёт тот же полный спрайт 160×128, пиксель в пиксель.
- Сам тайлсет речки **НЕ ИЗМЕНЁН**: он тот же, что в предыдущем техническом river pack FINAL.

## Файлы для установки

1. `tls_village_river_32.png` — тайлсет 128×160: 4 столбца × 5 строк, по 32×32 px, zero margin, zero separation.
2. `spr_village_bridge_deck_160x128.png` — спрайт мостового настила/задней части, должен рисоваться **за Макс**.
3. `spr_village_bridge_front_rail_160x128.png` — передняя часть и столбы мостика, должна рисоваться **перед Макс**.
4. `spr_village_bridge_full_160x128.png` — **только для сверки**, не рисовать одновременно с частями (иначе мост задвоится).

ВАЖНО: Для deck/front_rail одинаковые холсты 160×128, одинаковые origin и координаты (x,y), scale 1:1, nearest-neighbor. НЕ обрезать прозрачные границы и НЕ центрировать по разным bounding box. Не использовать прежние PNG моста (V1/V2/FINAL) — они заменены V3.

## Индексация речного тайлсета

Первые 16 ячеек — corner masks от 0 до 15: NW=1, NE=2, SE=4, SW=8, бит=1 означает ВОДУ. Ячейки 16–18 — три варианта спокойной воды; 19 — запасная трава. См. `TILE_INDEX_16_MASKS.csv` и `GUIDE_16_MASK_TILES.png`.

## Встраивание

1. GameMaker перед редактированием необходимо закрыть; проверить рабочую ветку и наличие незакоммиченных изменений.
2. Показать предварительный план русла и расположения моста **вдоль левого края rm_village возле Мэгги**, включая проход к выходу на ферму; ничего не передвигать до одобрения автора.
3. После одобрения импортировать тайлсет и мостовые слои, настроить глубину, коллизии воды и проходимость моста (не ставить solid на весь bbox).
4. Проверить Макс с направлений слева/справа, чтобы передние перила перекрывали ноги персонажа, а настил оставался позади.
5. Показать общий скриншот левого участка, мост крупным планом, список перемещённых объектов и изменённых файлов.
6. Не изменять другие комнаты, сюжетные флаги и квесты; без согласования не мержить в main.

`PREVIEW_...` и `EXAMPLE_...` — только для просмотра, **не импортировать** как тайлсет/спрайт.
